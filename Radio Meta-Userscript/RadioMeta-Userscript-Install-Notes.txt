Radio Meta userscript loader

Purpose
This replaces the Radio Meta loader modification appended to nowplayingbar.js. It does not replace Emby's built-in now-playing bar module; Emby's original nowplayingbar.js should remain installed.

Install
1. Install Tampermonkey or Violentmonkey in the browser.
2. Create a new userscript and paste in RadioMeta-IntegratedDisplay-Loader.user.js, then save.
3. Restore the stock nowplayingbar.js before testing. If the Radio Meta WebLoader installer created a backup, run Restore-WebLoader.ps1 from that release's WebLoader folder and type RESTORE. If that exact backup is unavailable, restore the stock file that matches your Emby Web version.
4. Close and reopen the Emby Web tab, then press Ctrl+F5.

Requirements
- The Radio Meta plugin must be installed and its ConfigurationPage?name=RadioMetaIntegratedDisplay.js resource must be available.
- The script is currently scoped to http(s)://emby.mekhanik.net/web/*. If you use a different Emby hostname, edit the two @match lines at the top of the userscript to match it.

Check
In the browser console, run:
window.__radioMetaDisplayLoaderState_v1366

Expected result: "loaded".
If it fails, inspect:
window.__radioMetaDisplayLoaderError
